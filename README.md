# Uncrashed : FPV Drone Simulator — 非公式日本語化パッチ

Uncrashed : FPV Drone Simulator のメニュー・設定・マップエディターなどの表示を日本語にする、**非公式**の翻訳パッチです。

開発元（Luminite）とは関係ありません。開発元へこのパッチについて問い合わせないでください。

## 注意

- **自己責任**でご利用ください。本パッチの利用によって生じたいかなる問題についても、作成者は責任を負いません。
- ゲームが更新されると、表示が英語に戻る、または正しく表示されなくなる場合があります。
- Steam ワークショップのマップ名など、利用者が作ったものは翻訳されません。
- 画像に描かれた文字など、一部の文字は英語のまま残ります。

## 対応バージョン

Steam 版 **Build ID 26145167** で作成しました。

## 導入方法

1. [Releases](../../releases) から最新の `Uncrashed_JP_P.pak` をダウンロードします（またはこのリポジトリ直下の同名ファイルを使います）。
2. Steam のライブラリで Uncrashed を右クリック →「管理」→「ローカルファイルを閲覧」を選びます。
3. 開いたフォルダの中の次の場所を開きます。

   `Uncrashed\Content\Paks\`

4. その中に `~mods` という名前のフォルダを作ります（すでにある場合はそのまま使います）。
5. `Uncrashed_JP_P.pak` を `~mods` フォルダに入れます。
6. ゲームを起動し、メニュー右下の国旗から **ウクライナ語** を選びます。  
   → 表示が日本語になります。

日本語にならない場合は、`Uncrashed_JP_P.pak` を `~mods` ではなく `Paks` フォルダの直下に置いて試してください。

## アンインストール方法

入れた `Uncrashed_JP_P.pak` を削除してください。  
ゲーム内の言語を英語などに戻せば、元の表示に戻ります（ウクライナ語の公式翻訳も、pak を削除すれば元に戻ります）。

## 翻訳について

- FPV の専門用語は、日本語の FPV 解説で一般的な表記に合わせています。
- 定訳のない用語は英語またはカタカナのままにしています。
